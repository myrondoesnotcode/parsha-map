# Vayetze: proposed fixes to shared files

From the final fact-check pass (2026-09-28, workflow wf_6b2dc982-d88). These files are shared by every story, so the `review/vayetze` branch does not change them. Each item gives the finding, what was checked, and the exact change proposed.

## 1. "In history" eyebrow on the History tab (R46): `src/redesign/Screens.tsx:166`

Now: `{eraYear(parsha) === null ? 'Other ancient stories' : 'In history'}`, above a paragraph (Vayetze's `historicalContext`) that ends with most scholars rejecting the Nuzi theory. A bare "In history" can read as saying the events are historical. (The tradition lens passed it because the era card below says no one knows when the events happened; the history lens flagged it.)

Proposed:

```tsx
{eraYear(parsha) === null ? 'Other ancient stories' : 'Historical background'}
```

Applies to every dated parsha, so it is a cross-story change.

## 2. "Route illustrative" tag outside the story (missed, visual): `src/redesign/DaylightMap.tsx` or `MapChrome.tsx`

With the story closed, `DaylightMap.tsx:417` draws the whole route (`target = story.route.length - 1`), but the only "Route illustrative" tag is `.dl-route-tag` in `StoryPlayer.tsx:219`. On the Today and Map tabs the Haran → Mahanaim line crosses the Euphrates with no tag.

Proposed: render the same tag whenever the route line is visible outside the story (`story.route.length > 1 && !storyOpen`), text `Route illustrative · lines join the stops in order`.

## 3. Luz vs Bethel confidence (missed, visual): `src/data/places.json` (generated by `scripts/processGeodata.ts`; set it there, e.g. in `PICKED`)

`a397042` "Luz 1" is `confidence: "medium"`; `a64f355` "Bethel 1" is `confidence: "low"`, at the same point (31.922778, 35.241389). Luz's description is "another name for Bethel". The Map-tab sheet prints `City · medium confidence` for Luz (`MapChrome.tsx:238`), more certain than the Bethel stop.

Proposed: set `a397042` confidence to `"low"`, matching Bethel. Optionally hide a place dot that coincides with a stop pin.

## 4. Euphrates drawn as one dot (missed, visual): `src/data/places.json` `a62dec4`

The Map tab draws the river as a point near Carchemish (36.829722 N, 38.015 E). Its sheet already shows the description "the Euphrates; the pin marks the upper river at Carchemish, west of Haran" (`MapChrome.tsx:248`). The story says the crossing point is unknown (31:21 names none); the Map tab does not.

Proposed description: `the Euphrates; the pin marks the upper river at Carchemish, west of Haran, not where Jacob crossed it (the Torah doesn’t say where)`.

## 5. Date bar says "Tradition" without naming it (missed, history): `src/redesign/MapChrome.tsx:49`

Now: `` `Tradition: ${formatBCE(...)}` `` → "Tradition: c. 1576 BCE · Jacob comes to the well, aged 77". The History tab uses "Traditional Jewish chronology". The Vayetze date comes from Seder Olam (`scripts/buildParshaDates.mjs`: `SOR(2)`).

Proposed: `` `Jewish tradition: ${formatBCE(...)}` `` (cross-story).

## 6. `approximateDateBCE` for the patriarchal parshiot (missed, history): `src/data/parshaList.json`

Vayetze has `{ start: 1850, end: 1650 }`, unsourced, and narrower than the sourced range in `parshaDates.json` (patriarchs 2000–1550 BCE, "or later"; McCarter/Hendel). The Daylight UI does not render it, but the classic UI does (`?ui=classic`, web only: `ParshaSelector.tsx:10` shows "1,850–1,650 BCE"; `ParshaHeader.tsx:155`; `utils/parshaUtils.ts` uses it to pick a parsha by year). Lech Lecha through Vayechi all carry similar unsourced ranges.

Proposed (decision for Myron, since it changes the classic timeline for ten parshiot): set `approximateDateBCE` to `{ start: null, end: null }` for lech-lecha … vayechi, or derive it from `parshaDates.json` `scholarly.patriarchs` (2000–1550). Not changed on this branch because a Vayetze-only change would leave its neighbours inconsistent.

## 7. Execration texts "the earliest Egyptian references" (missed, history): `src/data/timeline.json` `middle-bronze.primarySources[1]`

Rendered only in the classic UI (`src/components/context/PrimarySourcesCard.tsx`, via `ContextPanel.tsx`); not in Daylight. The superlative was not verified in this pass. Proposed if kept: "among the earliest Egyptian references to cities named in the Bible".
