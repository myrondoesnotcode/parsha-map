# Chayei Sarah story: self fact-check

Story: `src/redesign/stories/chayei-sarah.ts` (14 cards). Checked 2026-09-27 against sources fetched that day.

**Sources fetched.** Verses: Sefaria API v3, `Genesis.23.1-25.18` plus 11:27–31, 15:2, 16:14, 20:1, 22:19–23, 27:43, 29:4–5, 49:29–32, 50:13 (THE JPS TANAKH: Gender-Sensitive Edition; Hebrew: Miqra according to the Masorah). Rashi on Genesis 23:1, 23:2, 23:4, 23:16, 24:10, 24:39, 24:42, 24:57, 24:62, 24:63, 24:67, 25:1, 25:9 (Rosenbaum–Silbermann; 25:1 Sefaria edition), Hebrew and English. Ramban on 24:10. Bereshit Rabbah 58, 59:9, 60 (Sefaria Midrash Rabbah 2022). Pirkei DeRabbi Eliezer 32 (Friedlander). Berakhot 26b and Sanhedrin 95a (William Davidson). Wikipedia: "Cave of the Patriarchs", "Tel Rumeida", "Nahor, son of Terah". `src/data/places.json` for every pin.

**Not used, on purpose.** The Hittite-law (§46–47) comparison, which the Genesis fact-check flagged as outdated; the servant's name stated as fact; "first time the Torah uses 'love' for a marriage" and "first mourning" superlatives (not re-verified, so left out); any date beyond the automatic date bar.

Hebrew on quote cards is the Masoretic text with cantillation removed; no quoted Hebrew contains God's four-letter name.
